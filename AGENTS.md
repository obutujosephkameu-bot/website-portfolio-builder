# Project decisions

- Treat Software World as Lumex Digital's dedicated software-building department, not as a general website brand, so its presentation stays distinct from client portfolio work.
- Render the global cursor water wake with one pooled, pointer-transparent canvas and disable it for touch or reduced-motion users to preserve performance and accessibility.
- Keep glass click and route transitions as a global pointer-transparent decoration so existing navigation and actions remain immediate and accessible.
- Store public visitor reviews in Lovable Cloud with limited public insert/read permissions so posted reviews persist for all visitors without changing the existing Firebase admin setup.
